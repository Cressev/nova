# reports 目录说明

## 用途

本目录用于保存用户明确要求的结构化报告、归档文档、实验总结、评估总结和交付说明。

## 当前文件

- `2026-09-22-1318_nova-dsh-差异清单与验收指标.md`：Nova 对齐 DSH 的差异、验收指标、证据和剩余风险。

## 放置规则

- 只有用户明确要求“报告、归档、总结文档、交付文档”时才新增报告。
- 报告文件名必须以 `yyyy-mm-dd-hhmm_` 开头。
- 新增报告时同步更新本 README。
