## 使用说明

## 统一验收成功状态

全部对齐完成必须同时满足：

1. 后端全量测试稳定通过，当前基线为 `300 tests OK`；
2. 前端 `npx tsc -b`、`npm run build`、React smoke、Workspace 18/18、`git diff --check` 全通过；
3. 用户重启 Nova 后，`/openapi.json` 包含：
   - `/api/workspaces/rename`
   - `/api/workspaces/delete`
   - `/api/workspaces/reorder`
   - `/api/chat/sessions/reorder`
4. 真实浏览器完成：搜索、passive runtime、Workspace rename/delete/reorder、Session reorder、rail/wide 刷新恢复；
5. N11、N12、N13、N14、N15 不再处于“部分完成 / 待重启 / 未完成”；
6. 最终交付说明列出证据和剩余风险，不以本地测试替代实时服务验收。

## 当前结论

Nova 已完成 DSH Sidebar/session/workspace 主要交互和 Host 持久化代码对齐，当前不能标记为整体验收成功。阻断整体完成的具体条件是：运行中的 Nova 宿主尚未重启，新 API 尚未进入实时 OpenAPI；此外完整状态优先级、错误重试/IME 细节和最终提交仍需完成。
