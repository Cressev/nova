# Nova ↔ DSH 会话侧边栏差异清单与验收指标

- 日期：2026-09-26
- 方法：DSH 源码（`packages/client/ui-sidebar`、`ui-workspace/src/client/WorkspaceBrowser.tsx`、`rows/Rows.tsx`、`tree.ts`）+ 双侧线上实测（DSH http://127.0.0.1:3080 只读观测、Nova http://127.0.0.1:8765）。
- 结论摘要：Nova 侧边栏的骨架（分组树、行菜单、拖拽、键盘、几何 279/56px）已对齐 DSH；差异集中在 **会话创建时机、时间可读性、悬停互换、搜索形态、视图菜单、折叠编排** 六处，其中"新会话立即落库"是用户侧"历史会话被占位淹没"的根因。

---

## 一、高优先差异（P0：直接解决"找不到历史会话"）

### D1. 新会话创建时机：DSH 首条消息才落库，Nova 点击即建真会话

| | 行为 |
| --- | --- |
| DSH | `startSession()` 只产生**空白占位行**（blank node）：显示"新会话"文案，**无时间戳、无 ••• 菜单**（重命名/分叉/归档对不存在的内容无意义）；首条消息发出才真正创建会话；放弃则无任何痕迹 |
| Nova | 点击"新会话"立即 `POST /api/chat/sessions`（title=新线程）并选中；放弃后留下永久占位会话 |

- 证据：Nova 线上 10 个会话中 5 个是 `新对话/新线程` 占位（`chat_faf7c60a72ec`、`chat_9e3ddb3fe6a1`、`chat_7af1e96e219c`、`chat_7a48058933ac`、`chat_583c7ed27a96`）；DSH 源码 `WorkspaceBrowser.tsx` blank 行注释："nothing has happened in it yet, so a 'now' timestamp and the row verbs would all act on content that does not exist — both trailing cells stay off until the first prompt"。
- 验收指标：
  1. 点击"新会话"后 `GET /api/chat/sessions` 数量不变（无新会话落库）；
  2. 侧栏出现一条空白占位行（标题"新会话"、无时间、无菜单）；
  3. 在占位行发首条消息后才产生会话记录，标题走自动命名；
  4. 点击其他已有会话或刷新页面后，未使用的占位消失，列表无"新对话/新线程"残留；
  5. 存量占位会话（标题为占位且零消息）在列表中折叠进"未命名"桶或被清理入口处理，不再与有效会话混排。

### D2. 相对时间桶缺失"天/月/年"，超一天直接变 `M/D` 数字

| | 行为 |
| --- | --- |
| DSH | 六桶：`刚刚/N分钟/N小时/N天/N个月/N年前`（`tree.ts relativeTime`：MIN/HOUR/DAY/30*DAY 分桶），悬停卡用"N 前"模板 |
| Nova | 四桶：`刚刚/N分钟/N小时/M/D`——超过一天显示 `9/23` 这类裸日期，历史会话时间可读性差 |

- 证据：DSH 线上行内时间实测 `1分钟`、`4天`；`frontend/src/lib/api.ts relativeTime()` 第 4 桶直接 `getMonth()+1 + "/" + getDate()`。
- 验收指标：行内时间输出仅含 `刚刚|N分钟|N小时|N天|N个月|N年` 六种形态；`9/23` 形态不再出现；悬停卡带"N 前"措辞。

## 二、中优先差异（P1：交互形态与 DSH 不一致）

### D3. 会话行"时间 ↔ •••"未做悬停互换

- DSH：悬停行时右侧时间隐藏、省略号菜单出现（CSS-only 互换，行尾宽度占用恒定，figma Cell 规范）。
- Nova：时间常驻（实测 opacity=1），••• hover 才出现——两者同时可见，行尾拥挤。
- 验收：hover `.session-item` 时 `.session-time` 隐藏且 `.session-more` 可见；移出恢复；行宽无跳变。

### D4. 搜索形态：DSH 头部内联展开 + 独立结果列表；Nova 开关输入框 + 树内高亮

- DSH：收起时是头部图标，点击展开为输入框（`searchSlotExpanded`），带清除按钮；Esc = 清空并收起；250ms debounce 远程内容搜索；查询上限 500（含代理对安全截断）；结果为**独立平铺结果列表**（状态点 + 标题 + 工作区上下文 + 内容摘要 + 结果数上限 + pending 状态行）。
- Nova：`searchOpen` 开关一个独立输入框；无清除按钮、无 Esc 关闭、无 debounce；结果 = 分组树原位高亮 + 行内摘要，无独立结果列表、无"无结果"空态。
- 验收：① 头部图标点击展开、再点清除/Esc 清空并收起；② 输入防抖 ≥200ms 才发远程请求；③ 有查询时列表切换为平铺结果形态（标题+工作区+摘要）；④ 无结果显示空态文案。

### D5. 视图/排序：DSH 一个"视图选项"勾选菜单；Nova 两个常驻文本按钮

- DSH：`ViewOptionsMenu`（个性化图标）→ portal 菜单：`分组` 标签行（按工作区 ✓/单列表 ✓）+ 分隔线 + `排序` 标签行（手动 ✓/最近 ✓），dense、selectedIds 高亮当前态。
- Nova：头部常驻 `树/平铺`、`最近/手动` 两个文本按钮逐次切换，无当前态勾选、无标签分组，占头部空间。
- 验收：单入口菜单；当前分组与排序带勾选标记；菜单含"分组/排序"两个标签行与分隔线；portal 渲染不被头部裁剪。

### D6. 折叠导轨缺"添加工作区"入口；搜索图标为文本字符

- DSH 实测：折叠态 56px 导轨竖排 4×36px 图标 = `打开侧边栏 / 新建会话 / 添加工作区 / 搜索会话`；点搜索自动展开侧栏并聚焦输入框（`searchOnExpand`）。
- Nova：折叠态保留 brand/新会话/搜索⌕/设置；缺"添加工作区"；搜索按钮是文本 `⌕` 字符。
- 验收：折叠导轨含添加工作区入口；搜索为 SVG 图标；点导轨搜索展开侧栏后输入框自动聚焦。

## 四、已对齐项（本次核对确认无需改动）

分组树 + 每组 5 条折叠 + “展开其余 N 条/收起”；行菜单（重命名/创建分支/归档，无删除——与 DSH 一致，删除走归档语义）；工作区重命名/删除（带确认）；会话组内拖拽排序 + 工作区拖拽排序（插入线+失败回滚）；键盘导航（Enter/↑↓/Space）与 `role=tree/treeitem`、`aria-expanded/selected`；状态点 5 态主体语义（pending > running > completed-unviewed > idle）；宽度几何 279px 展开 / 56px 折叠（DSH 实测 280/56，等差 1px）；底部设置固定；fork 谱系（Nova 另有 ⑂ 图标，为超出 DSH 的自有增强，保留）。

## 五、建议实施顺序

1. **D1 + D2**（P0，一次提交）：新会话延迟落库 + 空白占位行 + 六桶时间——直接消除占位会话堆积。
2. **D3 + D4 + D5 + D6**（P1）：行尾互换、搜索重构、视图菜单、导轨补齐。
3. **D7–D13**（P2）：按剩余清单逐项对齐。
